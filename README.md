# IdeFunctionLab

## Cel
Program oblicza funkcję f(x) = 2x + 3.

## Uruchomienie
Polecenie: `dotnet run`
Przykład: dla x = 4 wynik to f(4) = 11.

- Visual Studio: wynik kompilacji, uruchomienia i obserwacja debuggera.
